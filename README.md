# Individual Neural Holonomy — integrated final analysis v1.0.0

This archive is the submission-oriented, reproducible integration of Stages 1–5.
The original uploaded archives are preserved separately; all corrections and
reruns in this directory are versioned as a new analysis.

## Scientific scope

The strongest supported target is deliberately narrow: in a controlled,
rank-two complex-fiber/SU(2) simulation, history-dependent remodeling can
separate the stable regime from the modeled non-stable regimes under
clone-specific matched probes, and
selected conjugacy-invariant scalar and within-clone metric descriptors can be
recovered under the declared synthetic multichannel observation model.

This package does **not** establish real-ECoG validity, phenomenology, unique
experience, a full neural connection, unrestricted cross-subject gauge
identification, or fast-RIC causality.

## Directory map

- `stages/`: corrected, runnable Stage 1–5 source packages.
- `integrated/results/`: complete rerun artifacts and machine-readable summaries.
- `integrated/tables/`: manuscript-ready CSV/XLSX/LaTeX tables.
- `integrated/figures/`: publication figures in raster and vector formats.
- `integrated/manuscript/`: paste-ready Methods, Results, captions, report, and PDF.
- `integrated/qc/`: independent recomputation, checksums, environment, and visual QA.
- `docs/FINAL_ANALYSIS_PROTOCOL.md`: estimands, splits, nulls, decision rules, and claim boundaries.
- `scripts/`: one-command rerun and independent audit utilities.

## Reproducibility

Run commands and exact environment details are written after the final run to
`integrated/qc/REPRODUCIBILITY.md`.  All stochastic analyses use fixed,
condition-independent seed streams; all confidence intervals resample the
independent clone unit rather than branches or repeated observations.
